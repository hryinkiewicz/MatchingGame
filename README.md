
Match Game (Игра в сопоставление значков)

Простая и увлекательная игра для развития памяти и внимательности, в которой игроку предстоит искать парные картинки.

Игра представляет собой сетку карточек 4x4 (на базе TableLayoutPanel), где скрыто 8 пар случайных значков. Игрок поочередно открывает карточки, пытаясь найти одинаковые символы. При каждом старте значки перемешиваются с помощью класса Random. 
Совпавшие пары навсегда остаются видимыми (цвет текста меняется на черный). Если картинки не совпали, встроенный таймер автоматически скрывает их через 0.75 секунды, давая время на запоминание. Система непрерывно проверяет поле. Как только все пары открыты, появляется окно с поздравлением, и игра закрывается.

Руководство пользователя

1. Запустите игру, нажав клавишу F5 или кнопку Пуск.
